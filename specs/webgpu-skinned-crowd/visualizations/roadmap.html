WebGPU Game Port Roadmap

Raw WebGPU runtime for the whole browser game: crowd renderer first, then battle terrain and UI, campaign map and panels, menu shell, verification, performance, and production cutover. Current-game parity is the floor; the release target is better graphics and better performance.

Rule: no slice waits for real art. If a required asset is missing, generate a placeholder, validate the contract, and make the workbench explain what a real replacement must provide. A lab route is a checkpoint, not the finish line; the finish line is the default game route outperforming and looking better than the current renderer.
