## Decisions I made

- **Separate module rather than folding into the history.** The history's return is `begin`/`commit`/`abort`/`check`, which must not appear on an audience's public surface, so the diagnostics needed their own object anyway; giving them their own file keeps publication policy and diagnostic reads each nameable.
- **Left the photoreal renderer alone.** `packages/photoreal-renderer/src/battle/battleWorld.ts:535` has its own `1e-3` seating compare and `crowdLayer.ts:437` its own `debugSoldierAnim`. That's a different crowd layer, not a consumer of this history — folding it in would be the broadening the contract forbids.
- **No README edit.** Nothing in the candidate README became false; the new surface isn't described there, and the scope list doesn't include it.
- **Left `crowdAudienceHistory.ts`'s pre-existing formatter drift alone** (the `lod` import block reflows under `oxfmt`, but `packages/**` isn't covered by the repo's format script) rather than add unrelated churn to this diff.
