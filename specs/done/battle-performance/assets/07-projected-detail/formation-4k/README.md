# The 4k formation retains native-scale readability

The same 64-soldier ready/thrust camera reversal compares original near geometry
(left) with the 4k candidate (right) around a trial 32-pixel near boundary. Actual
admissions, all-soldier coverage, exact frozen repeats and return endpoints pass.
Root inspects every frame and enlarged crop. Independent unprimed review finds no
obvious formation-wide color flash, equipment or silhouette loss. The candidate
interior is marginally softer/lighter in the smallest enlarged crop; the reviewer
cannot substantiate a meaningful native-scale defect. Grounding is comparable.

This makes 4k the stronger phalanx candidate for this bounded interval. It is not
full roster, lower-tier, close-view, shadow or live-performance acceptance.
The candidate's repeated native-scale cost remains to be measured after a concrete
adoption policy is selected. Production assets and thresholds remain unchanged.
These fixed-pose sampled reversals use Chrome/Metal 1280×800, DPR 1, with frozen
light/time; they do not replace canonical software-rendered regression baselines.
