# Cascade contract audit

The independent read-only Claude audit is retained with root's item-by-item
disposition. Accepted corrections remove duplicate camera data (208-byte receiver
block), name source cold/moving caster-admission lag, distinguish normalization and
valid-depth differences, and require an internal overlap-weight check. Claims
that the current native camera has no finite far or that a small source margin is
zero were rejected against actual code and the direct pinned CPU oracle. A WebGL
fade difference does not redefine the current WebGPU product contract.

The synthetic CPU oracle covers four finite far planes and records source breaks,
frustum vertices, fit positions/bounds and per-cascade bias. It is neither a
browser visual verdict nor proof that the suspected source seam exists. The
materialized M6a spec owns the corrected implementation contract; no GPU or
production code changed in this review.
