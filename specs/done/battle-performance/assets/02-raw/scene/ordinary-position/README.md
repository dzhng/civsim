# Assembled scene with ordinary terrain positions

Eight presentations retain matching source/native soldier, main-view, shadow-only and L3 counts. The added far view selects and draws all 15,560 soldiers through the twenty prepared impostor atlases. GPU/browser errors and remaining tracked buffers/textures are zero. These are composition controls, not measured performance or complete backend admission.

[Report](report.json) preserves every numerical difference. Settled tactical, wide and horizon pairs differ at 30,339, 15,937 and 17,562 pixels. The far pair differs at 233,067 pixels, almost all by one channel code; only two pixels exceed one code. Exact image equality is not claimed. The first tactical source frame still has the earlier grounding/highlight discrepancy.

[Fresh review](visual-review/review.md), with A=Three and B=native, finds no visible one-sided lost formations, displaced labels or gross shading/cue regression in the settled pairs. It also identifies the severe common limitation: fixed-size labels obscure rear formations in the horizon and far views. The far case proves actual L3 resource/submission integration and some visible colored formations, not detailed readability of concealed soldiers. It is an additional diagnostic beyond the benchmark's camera tour.

The generated terrain is smaller than the real benchmark map. Water/vista and whole-scene settings/resize/replacement controls, exact recorded publications, actual live Menu integration and timing remain required.
