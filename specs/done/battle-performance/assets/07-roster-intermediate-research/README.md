# Unpublished intermediate-mesh research

This experiment is retained as evidence, not shipped as the production catalog.
The user directed closeout around demonstrated gains and the TypeGPU migration;
no mesh or LOD threshold was changed for this experiment.

The candidate keeps detached components and the twelve-triangle island floor,
reducing eighteen source assemblies used by twenty appearances from roughly four
thousand to two thousand intermediate triangles. The rig, material/image data,
other mesh tiers and animation files were byte-identical. All source validation
and 104 paired posed cases completed; independent review found no clear equipment
loss at the sampled scale. These stills do not establish continuous-motion parity.

Twenty-four balanced isolated GPU blocks show tactical main-pass medians of
13.65 to 10.97 ms at 200 m, with unchanged shadow work. The 600 m view is effectively
unchanged. This is a matched isolated GPU result, not a live FPS improvement.

One real five-minute menu benchmark completed with these candidate mesh overrides:
23.41 average FPS and an 8.64 FPS 1% low. It used live simulation and the camera
tour, with no invalid frames. It is observational: differing ending ticks prevent
ranking its FPS against older live runs. The compressed full report and small
summary preserve that distinction. The final production benchmark is separate.
