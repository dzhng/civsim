# Complete-roster intermediate chain

**The three-mesh arrangement is not adopted.** It establishes a useful tactical
opportunity, but increases distant and shadow work. The next implementation is a
four-mesh chain retaining both original low-detail meshes. Production catalogs
and policy are still unchanged at this checkpoint.

## Asset and visual boundary

Claude prepared all twenty appearances from eighteen verified saved sources.
The candidate chain is original near / approximately4k triangles / original
middle. [Source proofs](proofs) and [integration checks](root-integration-proof.json)
preserve original near geometry, motion, materials, images, bounds and far
impostor source. The integrating agent checked bytes against the main worktree,
not only the worker's source checkout. [Counts and hashes](summary.json) own the
per-appearance facts. Prototype bytes remain under root throwaway/roster-4k-chain;
no source assets have been replaced.

[Visual pairs](visual/report.json) show all twenty appearances as sixteen-person
formations at28 physical pixels of standing height, in canonical ready and
sampled melee poses. Original is left, intermediate is right. Each frozen capture
repeats exactly; the actual main tier is asserted. Root inspected all ten sheets;
an unprimed reviewer independently inspected all sheets and selected individual
pairs. Neither found a discernible missing-equipment, silhouette, pose or grounding
regression at this scale. Fine armor shading changes remain a consideration, and
thin polearm aliasing is present in both. This supports continuing the candidate;
it is not an animation, dense-battle or camera-motion acceptance verdict. The
three-mesh shadow proxy also differs from the proposed four-mesh arrangement.

## Same-world cost control

[Summary](cost-summary.json) and [raw observations](cost-report.json.gz) retain an
ABABA control at canonical tick9000, hash9928381812590497427. One world retains
its materials, palette and instance resources throughout; only vertex/index
attributes in mesh levels1/2 and shared projected boundaries change. The
candidate uses32/18/4; original uses18/9/4. Both main and shadow meshes participate.
Original source bounds remain valid because candidate manifest bounds match.
Geometry work below is counted from actual active draw buffers, not asset stats.

Each camera warms five seconds, clears both audience histories at the settled
endpoint, then waits another second before eight seconds of measurement. This
avoids the unmatched-history failure observed in the skin experiment. Original
counts and actual cameras agree across all three return arms in all four views.
GPU samples are joined to measured submission IDs; incomplete tail coverage is
reported. There are no simultaneous builds, bakes, tests or second task GPU jobs.
The host is shared and no complete quiet-host audit was made. These are
conditional stationary measurements, not final live acceptance or backend ranks.

vertices by about31%. Preserve that original far mesh instead: the next chain is
near / intermediate / original middle / original far, followed by the existing

per-view workaround. Four-mesh acceptance still requires its own work counts,
quality through every transition, standing gate and full live measurements.
