# Initial real-tier production measurement

The first reduced tiers are structurally usable, but are not a sufficient runtime budget. Editable heavy near remains 127,196 triangles; medium near remains 155,190. Preserving those meshes as runtime near was an explicit initial control, not a performance acceptance.

## Visual control

The final four production LOD sheets passed their normal exact baseline comparison (session 53697), all actual tier admission checks and 36 immediate frozen-image repeats. Near/mid/far were admitted through the production camera and bucket owner. The separate diagnostic then magnified those already admitted buckets without another upload. These magnified views are not evidence that a coarse model looks good close up.

The first context sheets were rejected despite correct numerical tier counters: the camera render shared a browser frame with the preceding close workbench frame, retaining cached camera uniforms. Advancing one actual RAF before admission corrected the rendered projection. The first broad dark-area oracle then failed because it included dark outer grass. The final oracle measures a fixed central 160×120 region inside the inspection pad, not the complete silhouette. Both rejected reports remain archived. No existing snapshot tolerance changed.

Independent unprimed review of all four final sheets found no clear missing limb, detached large weapon/shield or exploded skinning. It explicitly retained angular shields, triangular shading and low confidence in small attachments. Actual distant figures were too small to prove attachment completeness. This is bounded structural retention, not animation, contact or cosmetic acceptance.

One Preview window opened at 10:24:24 UTC and closed at 10:29:45 UTC on 2026-09-08 without feedback. Silence was not approval.

## Hardware scope

The existing animated benchmark ran on Chrome with `VERIFY_GPU_ADAPTER=hardware`, reporting `apple / metal-3`: 30,000 soldiers, 1280×800, the existing close gameplay camera, 60 warm-up frames and 180 samples per control/timed steady/interruption group. The 33 ms gates and actual production clock were unchanged. Genuine loaded manifests supplied roles; no synthetic geometry override was applied. The interruption schedule exercises walk/run changes here, **not all combat actions**: these foot manifests have no release binding.

An unrelated, longstanding user Chrome GPU process and other user Chrome work were active before the measurement. They were not terminated. These are observed hardware results, not exclusive-device timings or a clean comparison against the earlier synthetic fixture.

Heavy session 19390 finished with eight timing failures and no page errors. Main-view admission was 2,546 original near figures and 3,354 mid figures; another 24,100 were shadow-only, with all 30,000 admitted at the coarse shadow tier. Original near alone contributes 323,841,216 triangles per main geometry pass (2,546 × 127,196); this arithmetic is a workload count, not a measured GPU attribution. The complete renderer reported 702,514,021 triangles across its passes.

The next bounded correction keeps the original editable/inspection source, but reduces runtime near as well. This changes asset geometry budgets, not renderer LOD thresholds, simulation or the 33 ms acceptance criterion. There is no retry-until-green loop.
