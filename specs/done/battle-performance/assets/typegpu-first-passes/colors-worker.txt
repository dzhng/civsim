## Limitations

- Consumer wiring is proven at WGSL-resolution level (real `impostorSurfaceWgsl` / `overlayFunctions` bodies bound to the typed helper resolve with exactly one shared definition), at bundle level, and by an ownership test — the full crowd/impostor **pipelines** were not re-compiled on hardware, since that needs the replay fixture and impostor atlas.
- `mix`/`step`/`select` equality is established on Apple Metal only; one adapter, one run.
- No timing or parity claim; production still compiles the raw WGSL.
- One transient: a `page.evaluate` failed once because the Vite dev server reloaded mid-wait, and an earlier run served a stale module right after an edit — rerunning after the server settles is green, and the README says so.
