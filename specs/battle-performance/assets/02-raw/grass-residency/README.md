# Native grass publication

The native field consumes the shared `BattleGrassResidency` state machine. Base and focus-ring layers retain pipelines and geometry across record revisions. Unchanged revisions produce no upload; shrinking records reuses capacity; growth admits replacement record/visibility buffers before publishing them. Failed growth retains the prior valid buffers and count. Frame preparation must complete before routing or drawing, and callers must submit the preceding frame before replacing its records.

Blade geometry, thinning and translucency policy have one renderer-independent owner. The Three adapter imports the same values. Sampling budgets, cancellation and synchronous settle behavior remain the production baseline; this pass introduces no residency optimization. Both layers draw in source tier order, with all optional near/mid depth draws preceding beauty.

The authored control compares actual Three base/ring indirect commands and HDR pixels across settle, unchanged publication, pan, far suppression, overview and terrain replacement. Exact draw counts do not imply exact raster coverage. The strict gate requires finite output, exact alpha coverage and shared covered RGB error at most 1/255. Paired PNGs use identical clipped linear-to-sRGB conversion for inspection only; numerical gates use unclipped HDR values.

`before-tier-order.json` preserves the initial diagnostic: all routes matched, but coverage differed by 1/1/17/31/0/1 pixels across the six states. Source prepass was disabled. The adapter initially grouped all base tiers before all ring tiers, unlike production tier-major ordering; this was corrected without changing the gate. `report.json` records the corrected run: the same strict differences remain (maximum shared RGB error 0.05927 for pan, at most 0.000855 for initial/reset). No error or warning was emitted. The pan/far-hidden camera lies beyond most of the small authored patch; the far-hidden source image is empty and native has 31 covered edge pixels. These are routing/history stress cases, not sufficient beauty framing. A red field report is an open component gate, not an accepted precision exception. Full-scene and temporal visual review remain required.

The existing frozen routing/beauty/prepass control was rerun separately under `../grass/mutable-runtime/`; it preserves its original precision criteria and native prepass invariance. CPU tests additionally cover capacity growth/shrink/empty publication, admission failure, disposal and stable pipelines across actual shared residency histories.
