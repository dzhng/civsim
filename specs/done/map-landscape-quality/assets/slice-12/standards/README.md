# One standard instance contract

Campaign settlement and army standards need their authored tier, livery and wind
without owning another GPU material. The shared contract now carries those
inputs, while existing battle unit identity preserves its deterministic phase and
selected treatment. Static mesh tiers are buckets within one material owner.

Verification isolates standard behavior from the unrelated full-battle grass
capture limit. The parent physical standard layer was temporarily restored and
captured with the same selected battle input, camera, time and environment. The
candidate matches that control exactly. All five existing campaign composition
frames also remain exact. The new mixed-tier and animated frames repeat at zero
pixel differences, with no GPU errors. Growth beyond initial buffer capacity and
subsequent shrink restore the original pixels. The zero-wind settlement changes
zero pixels while the moving cloth changes 1,122; the two custom fields have
2,663 green and 1,567 pink pixels in their independently selected cloth regions.

The mixed fixture deliberately uses distinct field, trim and emblem colors to
expose dropped channels. Those colors are test input, not new campaign art
choices. [Crops](landscape-standards-crop.png) and the
[later wind frame](landscape-standards-wind-crop.png) show the actual output.

Independent code review found no actionable defects. Local review also updated
the battle adapter's presentation cache key to include the newly shared tier,
livery and wind fields, so changing those inputs cannot reuse a stale frame.
Typecheck and all 492 web tests pass; the two new focused tests pass independently.

An unprimed image reviewer found no definite clipping, tearing or disconnected
geometry; cloth tops align with crossbars. It noted flat-looking cloth/metal and
faint gold-on-blue markings. Those are retained appearance limitations: the
selected battle image and existing campaign controls are byte-identical. The
center flag's lower tail changes side as it flutters; no tear or attachment defect
was established. Accept the input/lifetime consolidation, not a new material
quality claim. Real campaign entity/livery composition remains the later slice12
work.
