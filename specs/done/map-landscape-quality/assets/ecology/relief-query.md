# Shared campaign relief query

Geometry and planting eligibility must ask the same source interpolation and
height function. The relief sampler owns that calculation; the mesh owns finite
differences, topology and rendered seating. A caller supplies canonical coast
distance and detail spacing, preserving the coarse-grid frequency filter.

The extraction was compared with its parent on the coastal fixture at 2, 8 and
16 km spacing. Every vertex, color, tint, index, shore distance and prototype tree
was identical. The ten merged natural/clay captures also repeat with zero changed
RGBA pixels. Independent code review found no actionable regression; it did not
claim browser verification. Planting policy changes have their own acceptance.
