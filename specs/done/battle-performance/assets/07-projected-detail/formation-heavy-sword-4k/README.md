as the phalanx control: original near left, 4k intermediate right, trial near
boundary 32. Actual coverage, hysteresis, frozen repeats and return endpoints
pass. Root reads every frame/crop and an independent fresh reviewer judges them.

The candidate retains recognizable formation/equipment in this bounded view;
this does not establish animation-wide, lower-boundary, all-appearance, shadow or
live-performance acceptance. Production assets/policy remain unchanged.
