# Production raw palette hardware control

The raw-pose-palette scenario passes on hardware Chrome after promotion. It
checks weighted authored geometry/depth, per-occurrence palettes, GPU validation
and resource release. It does not measure frame cadence or prove the final world
passes the30k floor. Root first launched Vite from the repository root, which
served the wrong public directory and produced404s; those startup-failure reports
are retained separately. Restarting from web/ fixed the server root, then the
unchanged scenario passed. Both browser and server were closed after the run.
