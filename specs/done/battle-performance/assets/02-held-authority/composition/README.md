# Approximate contact-frame composition

All four fixed builds are captured near15 seconds of the same held tick9000 tour,
at1440×900 CSS and DPR2. Capture time differs slightly: judge gross composition,
not pixel identity or pose equality. Root inspected the contact/terrain details;
an unprimed reviewer inspected all four full images and eight crops.

The reviewer found no obvious candidate-specific missing formation, gross
placement error, floating army, terrain hole or depth failure (moderate confidence).
Root inspection agrees. This does not close exact parity or motion acceptance.

Shared issues remain: bright translucent blue/gold contact marks obscure soldier
silhouettes; densely packed figures merge at this scale; speckled grass contrasts
sharply with the smooth brown terrain. The benchmark panel occludes part of the
upper formation and card labels truncate. Scattered soldiers show shadows, but
these images cannot establish readable individual grounding inside the dense ranks.
No water, realtime motion, final shadow-quality or performance verdict follows.

Keep the contact-mark band and dense grounding in the final readability check.
Do not hide these layers to make a renderer benchmark cheaper. Existing HUD label
layout is shared and outside this performance pass's redesign scope.
