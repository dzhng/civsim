# Rejected source-rock slope gate

A bounded material hypothesis multiplied campaign source rock by exposure across
the existing rolling-to-slow slope interval. Geometry, source data, water, lighting,
vegetation and battle were unchanged. Static review and focused tests passed;
production before/after captures used the same frozen camera states.

The candidate changes 37,046 Alps pixels, 9,166 Italy pixels and 66,650 close Alps
pixels (RGB MAE 0.406/0.101/0.775). Root and unprimed review reject it as a solution:
some existing shelves gain useful grass, but much of the added green becomes thin
ribbons, flecks and stair-stepped edging on the same tightly packed rounded ridges.
Italy barely improves. This is the material recolor the acceptance contract says
not to substitute for broad valley floors and foothills. Candidate code is removed.

The next form pass must create intermediate shelves or wider valley floors within
the accepted geographic envelope, then let material and vegetation follow those
surfaces. Do not repeat this isolated coverage gate or earlier rejected erosion,
noise/resolution and raised-crest controls as if their failures were unknown.
The accepted downward saddle articulation and road-width fixes remain intact.
