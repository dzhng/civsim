# Rejected dominant-ridge support control

Multiplying the secondary fold field by squared dominant-ridge support measurably
widened low spaces on the exact campaign source while retaining upper relief.
The geometry-only regional comparison gave clearer continuous crests, but also
larger smooth walls surrounding dark hollows. A second control let source rock
follow the existing slope exposure on that fixed geometry. It exposed useful
green benches beneath Cambodunum and northwest of Aguntum.

Fresh regional review initially favored the combined result as a bounded step.
The required close review overturned that choice: regularly spaced triangular
teeth appeared on the foreground ridge and beneath Augusta Vindelicum, with
bright green seams on the stepped edges. Italy also gained a long retaining-wall
shape between Arretium and Spoletium. The overview benefit did not compensate
for the close regression. Both candidate source changes were removed.

The control images are the exact repeated accepted views in
[the earlier control](../source-slope-control/control). Candidate geometry and
combined exposures are retained here; pixel metrics separate geometry from the
subsequent material response. Focused16 terrain tests, typecheck and builds passed.
Production captures had no page errors. No candidate baseline was accepted or
repeat claimed. Any next form proposal must resolve near-view silhouette sampling
and interior green-space hierarchy together, not just improve low-slope area
measurements or recolor the same embankments.
