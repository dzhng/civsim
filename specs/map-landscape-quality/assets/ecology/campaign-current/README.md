# Campaign woodland checkpoint

The target is overlapping woodland cores, irregular edges and occasional outliers,
with trees subordinate to the mountains and seated on the displayed surface.
Regional before/after views use identical cameras and fixed time. Reference
geography differs, so its canopy organization is the target, not pixel distance.

The final independent review prefers the current distribution with high
confidence. Connected cores, smaller edge growth and clearer exposed slopes
improve over repeated broadleaf clumps. Remaining limitations are compact isolated
patches, some narrow tree chains, empty sheltered corridors and occasional simple
cone silhouettes. No definite floating trees were found. This accepts a bounded
placement improvement, not final whole-landscape quality.

`comparison.json` locates image differences; its distance metrics do not establish
quality. `source-probe.json` records an intermediate global generation measurement;
final density and species changed afterward, so it is not final performance proof.
Full UI/scenery traversal and final forest composition remain acceptance work.

The interaction fixture reproduces the former destroyed-buffer error during fog
membership changes. Capacity shrink now reuses storage; growth replaces geometry
identity so cached bindings cannot retain freed buffers. It checks repeated
unchanged submissions, terrain replacement, fog hiding/restoration and growth.

The composition baseline change belongs to material ownership, not planting:
restoring the former tiled material profile reproduces all eight old images
exactly. The new shared slope profile exposes rock on steep tiled ground while
all picking, road, label and terrain-replacement checks remain unchanged.

Final code review was interrupted by the external Codex usage limit. The previous
independent review identified the scenery fog omission, which is fixed and covered
by the browser scene. The final local review found no further correctness issue;
it retains the incomplete full-map scenery residency/performance gate explicitly.

The final combined repeat preserves all regional, composition, anchor, material
and water baselines exactly. Its growth fixture exposed one additional issue:
Three clones the aliased normal attributes into separate buffers. Re-aliasing
`normal` to `sNormal` after cloning preserves the device's vertex-buffer limit.
The focused growth repeat then passes all three exact images and every lifecycle
assertion with no page or GPU errors. The failed combined report and successful
focused repeat are retained separately so neither result is hidden.
