# Main-worktree ground composition

These actual-production frames combine accepted mountain-band exposure with the
accepted removal of disconnected rock props. All non-rock scenery records,
cameras and ticks match the isolated material candidate; global rock records
fall from973 to0. There are no page errors. The controlled source-band and prop
passes each have exact-repeat evidence; these are additional composed captures,
not newly accepted canonical baselines.

Fresh unprimed review confirms that mountains now read as continuous ground,
without detached bases or stickers, but explicitly rejects reference-quality
acceptance. Root agrees. Largest remaining visible gaps:

- Smooth inflated mountain folds, cloudy detail, triangular teeth and too few
  distinct rock/scree/grass shelf transitions.
- Bright wide roads crossing abrupt slopes as pale angular ribbons.
- Oversized isolated trees and sharply bounded groves with little scrub or
  intermediate ground detail.
- Uniform narrow shoreline fringes and stepped coast edges.
- IULIA CONCORDIA/AQUILEIA appear to run together in the lower Alpine frame.
  The next matched UI output replay records their actual boxes/anchors to
  distinguish overlap from inadequate spacing or contrast; this is not yet
  attributed to the source-band change.

The material texture prototype and remaining ecological/road/water/UI slices
own these gaps. The main branch passes538 frontend tests and typecheck at this
checkpoint. Full whole-frame and hardware acceptance remain open.
