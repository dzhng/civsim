# Crest prominence control: not adopted

At unchanged2km sampling, the dominant ridge term was multiplied by
`0.4 + 1.2 * campaignNoise(wx / 24 + 31, wy / 24 - 19)`.
Source geography and minor folds remained unchanged. The lab camera target was
pinned to the control elevation; both actual matrices matched exactly in regional
and close clay and natural pairs. Captures used1280×800,DPR1,SwiftShader,time0.
All runs completed without page errors;13 focused terrain/coast/surface tests passed.
No production capture, repeat stability, Italy acceptance or full-feature claim follows.

Two independent fresh reviews prefer clearer individual summits and saddles,
first in clay and then natural materials. Both flag amplified curtain walls and
thin fins, especially western overview and upper-right close peak. Root agrees:
added prominence is real, but raising ridge heights worsens an existing defect.
The candidate is not adopted, and the original formula is restored. No alternate
worktree or runtime mode remains.

Next bounded hypothesis: create saddles only by lowering short portions of the
existing crest, without raising any point above the parent. This isolates whether
summit distinction can survive without the amplified wall regression. Do not
claim that a one-sided height bound guarantees natural shapes; inspect the same
views and reject if regional relief is lost. The retained lab targetZ parameter
allows these comparisons to hold the actual camera fixed despite changed height.
