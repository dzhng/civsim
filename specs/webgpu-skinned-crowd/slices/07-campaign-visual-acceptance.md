# Campaign Visual Acceptance

## Contract

Campaign visual acceptance is human-readable evidence, not a global similarity
score. WebGPU may diverge from the previous renderer where it is clearly more
readable, more accurate, or better looking, but missing terrain, broken roads,
wrong water, absent forests, hidden mountains, or unreadable labels block
acceptance.

## Human Check

Review contact sheets and crops for the required campaign scenes. Ask for an
unprimed critique before accepting close Rome, central Italy, Italy overview,
whole map, fog, and road-continuity work.

## Verification

- Use compare-screenshots for side-by-side crops, grayscale/edge telemetry, and
  difference maps.
- Use screenshot-critique as a second set of eyes before accepting visual work.
- Keep accepted reference captures in this spec folder.
- Store reports under `visualizations/campaign-acceptance/`.

## Done

- Campaign captures are accepted for accuracy, playability, and visual quality.
- Any remaining divergence from the previous renderer is documented as an
  intentional improvement or release exception.
- The visual report no longer hides campaign blockers behind aggregate scores.
