# Downhill-link incision probe

Rejected on the first close clay fixture. No regional captures were run and no
production code, baseline, source schema or gameplay behavior is changed.

The candidate cut broad valleys along jittered links between every fourth
existing source-height sample and a lower neighbor. Each query inspected a
bounded local neighborhood with no retained graph or cache. The existing
geographic envelope, crest field and coastal attenuation remained authoritative;
incision could remove at most 35% of the folded relief, leaving the foothill term.

The [fresh comparison](critique.md) agrees with the rejection. The first image produces repeated diagonal ribs and trench-like bands on the
lit flank, plus isolated rounded nubs in the shadow. It does not establish the
connected, naturally branching valleys sought by 04. The extra edge energy is
therefore artifact evidence, not improved quality. Local downhill links over
the current source form are not accepted as the next structural solution.
No additional spikes follow this rejection without revisiting source form.

The frozen existing close fixture uses 1280×800 DPR1, 2km terrain cells, the same
clay material and SwiftShader. Its camera targets presented ground height, so
changed center height causes a slight framing shift. The capture has no GPU
validation or page errors and changes 586,136 pixels. [Telemetry](comparison.json)
measures grayscale MAE 3.00 and edge-energy ratio 1.25 against the prior frame;
these are change metrics, not closeness to a natural mountain.

CPU measurement over 10,201 fixture samples: prior queries 3.74–3.88ms versus
candidate 12.52–14.03ms, about 3.4× slower. The worst-case query adds 225 source
height reads and 25 segment distances. Sampled retained height is at least 66.47%
of the prior value; source arrays are unchanged, coast height remains zero and
repeat queries are deterministic. This synthetic timing is not production
hardware performance. Both geometry and ecological eligibility use the same
relief owner, as confirmed by [independent static review](code-review.txt).

TypeScript and the four existing campaign landscape surface tests pass, including
world-stable overlap and narrow source-water coverage. The bounded patch added 49
lines and removed one in the existing owner; its runtime complexity and visible
regression do not justify retention. The exact zero-context patch, query metrics,
full before/candidate frames and 2× feature crops remain as reproduction evidence.
No baselines, test thresholds or production decisions are repinned by this pass.
