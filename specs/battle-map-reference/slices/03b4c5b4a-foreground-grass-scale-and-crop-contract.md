# Slice 03B4C5B4A - foreground grass scale and crop contract

## Contract

Define the grass-only judging zones before any more renderer tuning. This slice
owns crop/mask selection and camera-scale diagnosis only.

The target has three different grass reads:

- **close hero foreground** - bottom foreground where grass body, strand direction,
  clump softness, and height variation are visible;
- **transition band** - foreground-to-midground area where strand detail starts
  collapsing into clumped soft body;
- **mid-mass** - midground/background meadow mass where individual strands should
  no longer be readable.

The current full `battle-map-reference` shot is too zoomed out to answer the close
hero question honestly. This slice must make that explicit with artifacts, not
try to fix it with grass constants.

## Approach

- Create target/current crop boards for close hero, transition, and mid-mass grass
  zones.
- If the current reference route lacks a comparable close foreground, record that
  as a camera-scale/composition fact and keep the close hero comparison assigned
  to the new lab in B4B.
- Archive crops under
  `assets/03b4-evidence/03b4c5-close-foreground-lab/target-crop-contract/`.
- Do not edit renderer code in this slice.

## Result (2026-07-01)

Accepted as a **crop-scale diagnosis**, not as a complete transition/mid
acceptance contract. Artifacts live under
`assets/03b4-evidence/03b4c5-close-foreground-lab/target-crop-contract/`.

The main learning is now explicit: the current full `battle-map-reference`
capture has no comparable close foreground grass layer. Current-side crops are
absence probes, not parity targets.

Final artifact set:

- `crop-contract-board.png` - overview with target zones and current absence
  probes.
- `target/*.png` and `current/*.png` - raw crop pairs for the diff helper.
- `labeled/*-side-by-side.png` - labeled target-vs-current absence-probe pairs
  for human review, so detached crop images cannot be misread as parity pairs.
- `diff/visual-parity-diff.json` - diagnostic metrics only.

Crop verdict:

- **Red close-hero** is accepted for handoff. It isolates close foreground grass
  body, visible strand scale, clump softness, and height variation without
  cliff/sky/water/fog contamination.
- **Orange transition** is a weak context cue only. It is the least-contaminated
  target-derived transition crop found, but neutral critique still says it does
  not clearly show the collapse from readable strands into unreadable body.
- **Blue mid-mass** is a weak context cue only. It demonstrates "no readable
  strands," but neutral critique says it is too featureless/atmospheric to be a
  strong mid-mass meadow target.

Final diagnostic metrics from `diff/visual-parity-diff.json` are not acceptance
criteria:

- close hero: `edgeEnergyRatio=0.45775`
- transition: `edgeEnergyRatio=2.27505`
- mid-mass: `edgeEnergyRatio=2.84914`

The high transition/mid distances mostly prove the current crops are absence
probes and the target crops are soft context cues. B4B1 must build a close grass
lab from the accepted red crop, then create clean lab-owned transition and
mid-mass review windows before B4D uses those variables as gates.

## Accept / Reject

Accept if a fresh reviewer can tell that red is the strong close-grass target,
that orange/blue are context only, that current-side crops are absence probes,
and that clean transition/mid gates must be generated by the lab/LOD slices.

Reject if the crop contract still asks one full-frame comparison to judge close
grass, midground grass, cliffs, water, sky, and fog at once.
