# Current native lifecycle acceptance

The final landscape build completes ten headful native campaign→TypeGPU battle→
campaign cycles. Each transition disposes every campaign terrain geometry once
and closes its terrain worker. Every requested battle buffer and texture returns
to zero. Retired campaign worlds and older renderers are collected. Live battle
resource counts remain constant after subtracting the telemetry owner's measured
retained buffers. User-agent memory is measured on every cycle.

The unchanged lifecycle scene passes with no page errors. The preceding software
run timed out at its22-second battle-start deadline; native execution satisfies
that same deadline without relaxing it. This proves the current lifecycle
contract, not release frame-time budgets or the original reference-quality floor.
