`paused-motion.json.gz` retains raw per-frame and periodic workload observations; `paused-motion-summary.json` is its compact index. Each hold/pan/zoom/horizon/combined phase ran for 60 seconds with the real HUD and 15,560 source soldiers, sim paused but rendering/animation live. This run is attribution evidence, not the live-game acceptance verdict or three paired rounds. No concurrent builds or GPU benchmarks ran during the capture. Raw rAF cadence is not physical presentation timing; existing GPU values are latest render-pass-only samples and cannot be added to CPU work or called correlated total GPU time.

The run verifies nonduplicate completed-loop samples, real rendered submissions, paused tick stability, real wheel response and frozen-cache submission behavior; no page errors. It **does not pass** the proposed performance target: phase means are roughly25–31fps, p95 gaps66–83ms, and pan max233ms. The harness's green status means valid measurement, not fast rendering. The shorter exploratory smoke was discarded as release evidence.
