# WebGPU Foundation Generated Evidence

This folder is the output target for broad WebGPU migration reports after the
active `specs/webgpu-skinned-crowd/` plan was retired. Keep this area for
machine-generated migration artifacts only. Campaign polish review evidence
belongs in `specs/campaign-polish/`.

The checked-in files here are tiny templates required by the cutover scripts.
Generated screenshots, diffs, reports, and scenario outputs may be recreated by
the WebGPU harnesses but should not be treated as the active campaign plan.
