zooms,1280×800,DPR1, fixed time and SwiftShader. Camera poses and both actual
matrices match exactly. Both runs finish without page errors. No repeat or
production acceptance is claimed: this is a rejected lab comparison.

high confidence, but finds regional mountain character essentially unchanged:
broad rounded slopes, ridge placement and valley structure persist. Root also
inspected both full-frame scales. Triangle count rises321,448→1,127,798 over

score quality. This is insufficient benefit to justify production refinement.

The earlier nine-requested-tile production failure is a swap-peak reservation,
not proof that nine fine tiles alone cannot fit. Residency still allowed16tiles;
old CPU/GPU buffers overlap new payload, morph/index copies and staging.
